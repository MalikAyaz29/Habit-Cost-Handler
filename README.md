# 🚀 Habit Cost Handler & Supply Tracker

**Experience the ultimate management system with a cutting-edge Cyber-Tactile interface.**

---

## 💎 Project Overview

**Habit Cost Handler** is a sophisticated **Progressive Web App (PWA)** built for users who value precision, aesthetics, and efficiency. Whether you're managing personal habits or tracking hostel supplies, this app provides a seamless, immersive experience.

---

## ✨ Key Features

### 🎮 Immersive Cyber-Tactile UI
- **Glassmorphism Design**: Beautiful translucent layers with depth and blur.
- **Haptic Feedback**: Micro-animations and audio cues that make the app feel alive.
- **Bento-Grid Layout**: Organized and responsive design that adapts to any screen.

### 📊 Advanced Tracking
- **Habit Cost Analytics**: Real-time calculation of daily, weekly, and monthly expenses.
- **Dynamic Supply Management**: Keep track of hostel essentials with an intuitive inventory system.
- **Live Currency Integration**: Real-time currency exchange rates for global accuracy (using public API).

### 🌐 Performance & PWA
- **Offline Mode**: Works flawlessly without internet using Service Workers.
- **Installable**: Can be installed on any device as a native app.
- **SEO Optimized**: Built with semantic HTML for maximum search visibility.

---

## 🛠 Tech Stack

- **HTML5**: Semantic structure and SEO.
- **Vanilla CSS**: Custom animations and premium styling.
- **JavaScript (ES6+)**: Dynamic logic and state management.
- **Service Workers**: PWA functionality and offline access.
